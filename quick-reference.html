🔧 Common Patterns

Button with Toast
Code
<button id="save-btn" class="btn btn-primary"> Save </button> <script> document.getElementById('save-btn') .addEventListener('click', () => { new Toast('Saved!', 'success'); }); </script>
Form with Validation
Code
<form id="my-form"> <div class="form-group"> <input type="email" required> </div> <button type="submit">Submit</button> </form> form.addEventListener('submit', (e) => { if (!form.checkValidity()) { new Toast('Invalid form', 'error'); } });
Delete Confirmation
Code
function deleteItem(id) { new Modal('Delete?', 'This cannot be undone.', { primaryBtn: 'Delete', onPrimary: () => { fetch(`/api/delete/${id}`, {method: 'DELETE'} ); } } ).show(); }
Stat Card Counter
HTML
<div class="card"> <div class="stat-icon">👥</div> <div class="stat-label">Students</div> <div class="stat-value" id="count" data-counter="2847"> 0 </div> </div>
JavaScript
new CounterAnimation( 'count', 2847, 2000 );
