HOW IT WORKS
================================================================================================

LOGIN FLOW:
  1. Staff enters numeric Staff ID (e.g., 19, 20, 21)
  2. Staff enters password
  3. System validates credentials
  4. If correct: Session created, redirected to dashboard
  5. If wrong: Error message, rate limiting applied

PROFILE MANAGEMENT:
  1. Staff accesses /staff/profile.php
  2. Can view: Staff ID, Name, Department
  3. Can change: Password, Profile Picture
  4. Cannot change: Any personal information

PASSWORD CHANGE:
  1. Staff enters current password
  2. Staff enters new password (min 6 chars)
  3. Staff confirms new password
  4. System updates database with new bcrypt hash
  5. New password works on next login
