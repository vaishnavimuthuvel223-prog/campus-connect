## 🔧 How to Use

### Quick Start (Copy-Paste)

**1. Add to `header.php`:**
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">
<link rel="stylesheet" href="/campuss/css/modern-design.css">
```

**2. Add to `footer.php`:**
```html
<script src="/campuss/js/theme-manager.js"></script>
<script src="/campuss/js/animations.js"></script>
```

**3. Update body tag:**
```html
<body data-theme="dark">
```

**4. Add theme toggle (navbar):**
```html
<button id="theme-toggle" class="theme-toggle">🌙</button>
```

✅ **Done!** Your entire site now has modern styling and theme support.
